# Changelog

## 0.1.0a1

Initial alpha: typed schema/intent/IR, logical planning, semantic mapping, structured confidence/provenance, capability validation, bounded schema retrieval and caching, provider-neutral structured interpretation, multi-turn structural refinement, deterministic backend compilers, explicit execution, source allowlists and execution-time revalidation.

SQLite and PostgreSQL reference paths; graph/document/Jira adapters; specialized TimescaleDB, Redis, InfluxDB 2, MySQL and HANA compilation/catalog support. HANA execution, InfluxDB 1/3, federation and other listed gaps are explicitly unsupported.

Includes CLI, 50 golden requests, cross-backend semantic tests, property/security suites, real-service integration tests, separate model evaluation, extension documentation and user manual. See VALIDATION.md for measured evidence rather than inferred maturity.
